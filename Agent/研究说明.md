# 逍遥丸干预单一抑郁障碍的网络药理学研究

## 研究边界

- 研究药物：逍遥丸。
- 处方组成：柴胡、当归、白芍、白术、茯苓、炙甘草、薄荷、生姜。
- 唯一疾病：抑郁障碍（Open Targets ID：MONDO_0002050）。
- 本目录不纳入焦虑、失眠或任何共病交集数据。
- 因逍遥丸与既有逍遥方研究的处方组成一致，S1–S12 药物侧数据按相同八味处方复用；S13 起疾病侧及所有下游结果均针对单一抑郁障碍重新计算。

## 关键参数

- Open Targets 关联评分阈值：0.1。
- GeneCards Relevance Score 阈值：31.0。阈值扫描显示 30 时药物–疾病交集为 510；首次达到 500 的精确临界值为 30.218447，因此采用整数 31 留出安全边界。
- GeneCards 与 Open Targets：任一来源达标即纳入，合并后按 Gene symbol 去重。
- STRING PPI：Homo sapiens（9606），required score ≥ 700。
- 完整药物–疾病交集保存在 `S16.Venn图-药物vs疾病.xlsx`。
- 当前完整交集为 480 个，未触发 STRING 的 2,000 个输入上限，S18 使用全部交集基因进行 PPI 分析。
- 核心基因筛选：DC/BC/CC/EC/KC 五中心性加权，最终采用综合评分前 10% 与多指标共识的交集。
- GO/KEGG：pvalueCutoff=0.05，qvalueCutoff=0.05，物种为人。

## 正式结果

- 逍遥丸药物靶点：3,438 个。
- 抑郁障碍 Open Targets 靶点：652 个。
- 抑郁障碍 GeneCards 靶点（Score ≥ 31）：1,060 个。
- Open Targets 与 GeneCards 合并去重：1,521 个，全部通过人源校验。
- 逍遥丸–抑郁障碍完整交集：480 个（满足不大于 500）。
- 药物–成分–靶点–疾病调控网络：1,088 个节点、6,853 条边（其中有成分证据的交集靶点 477 个，疾病节点仅“抑郁障碍”）。
- STRING 输入：全部 480 个交集靶点；正确映射 470 个。
- STRING 高置信 PPI：437 个联网节点、3,228 条边，33 个游离节点。
- 核心基因：44 个。
- 核心基因–成分对应：44/44 个核心基因有成分对应，共 1,157 条基因–成分记录、406 个相关成分。
- GO 富集：BP 1,966 条、CC 49 条、MF 96 条；KEGG 183 条。
