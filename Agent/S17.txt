S17 中药复方网络调控图布局规则
================================

一、总体结构

1. 网络层级为：中药 → 成分 → 靶点 → 疾病。
2. 疾病“抑郁障碍”固定在整张图的正中心，坐标为（0，0）。
3. 靶点围绕疾病节点排列为多层同心圆。
4. 八味中药分布在靶点圆外围，每味中药与其成分组成一个独立的圆形簇。
5. 每个中药节点位于其圆形簇的圆心，对应成分围绕中药节点排列为多层同心圆。
6. 所有坐标通过 Cytoscape View API 以 bypass 方式固定，不再使用 CoSE 等自动布局。

二、靶点同心圆规则

1. 靶点按标签（Gene Symbol）升序排列后依次放入各层圆环。
2. 第一层半径为 125。
3. 相邻圆环的半径增加 54，即：
   半径 = 125 + 圆环序号 × 54。
4. 每层容纳的靶点数随圆周长度增加：
   容量 = max（16，int（2π × 半径 ÷ 42））。
5. 同一层的靶点在 360° 范围内等角度分布。
6. 相邻圆环使用半个节点间隔的角度错位，避免形成完全重合的径向直线。
7. 疾病节点位于所有靶点圆环的共同圆心。

三、中药圆形簇规则

1. 中药顺序固定为：
   柴胡、当归、白芍、白术、茯苓、甘草、薄荷、生姜。
2. 八个中药圆心在核心靶点圆外围等角度排列。
3. 起始角度为 -157.5°，之后每味药增加 45°。
4. 中药圆心位于椭圆轨道上：
   X = 1130 × cos（角度）；
   Y = 970 × sin（角度）。
5. 每味中药节点固定在其成分簇的圆心。
6. 成分按成分标签升序排列，并由内向外放入多层圆环。
7. 成分第一层圆环半径为 82。
8. 相邻成分圆环半径增加 54，即：
   局部半径 = 82 + 局部圆环序号 × 54。
9. 每层容纳的成分数为：
   容量 = max（12，int（2π × 局部半径 ÷ 39））。
10. 同一层成分在 360° 范围内等角度分布。
11. 相邻成分圆环进行半个节点间隔的角度错位。
12. 一个成分同时属于多味中药时，仍保留其与所有相关中药的连线；其布局分组按上述中药顺序选择第一个相关中药。

四、节点样式

1. 背景颜色：白色（#FFFFFF）。
2. 中药节点：圆形，大小 62，字体大小 13。
3. 成分节点：圆形，大小 18，字体大小 6。
4. 靶点节点：圆形，大小 22，字体大小 7，绿色（#86B93F）。
5. 疾病节点：菱形，大小 76，字体大小 13，橙色（#F39C34）。
6. 节点边框宽度为 0.6，边框颜色为 #5F666B。
7. 节点标签置于节点中心。
8. 成分节点使用简短成分 ID 作为显示标签，完整成分名称保存在 full_name 属性中。

五、中药及成分配色

柴胡：#7569A7（紫色）
当归：#E31A1C（红色）
白芍：#E6B800（黄色）
白术：#263B8C（深蓝色）
茯苓：#D99AA6（粉色）
甘草：#32A7B5（青色）
薄荷：#E8862D（橙色）
生姜：#AA5A9E（紫红色）

每味中药与分配到该中药圆形簇的成分使用相同颜色。

六、连线样式

1. 连线基础颜色为灰色（#7B8185），不显示箭头。
2. 中药—成分边：宽度 0.75，透明度 135。
3. 成分—靶点边：宽度 0.48，透明度 72。
4. 靶点—疾病边：宽度 0.28，透明度 24。
5. 靶点—疾病边使用较低透明度，避免中心区域形成过深的线团。

七、数据与导出

1. 当前网络包含 1,088 个节点和 6,853 条边：
   中药节点 8 个、成分节点 602 个、靶点节点 477 个、疾病节点 1 个。
2. Cytoscape 完成布局后执行 Fit Content。
3. PNG 按宽度 5,000 像素导出。
4. 同时导出 SVG 矢量图和 CYS Cytoscape 会话文件。
5. 输出文件为：
   S17.中药复方调控网络-模板布局.png
   S17.中药复方调控网络-模板布局.svg
   S17.中药复方调控网络-模板布局.cys
